# Sabaq Check-in (tablet app)

The student check-in app for the Sabaq Tracker. It installs on the tablet and works with no internet:
saves are kept on the tablet and sent to the Google Sheet when the connection is back.

No student data is stored in this repository. The tablet is connected to the sheet once, on the tablet itself.

Arabic fonts: Amiri and Amiri Quran, SIL Open Font License (see `fonts/OFL-LICENSE.txt`).
